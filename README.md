# Browser Agent 1.0

Browser Agent 是一个 Chrome 扩展，可根据当前网页的可见 DOM 与无障碍语义，规划并执行浏览器任务。它会围绕用户目标读取页面、选择控件、执行操作并核验页面变化；遇到缺少信息、登录门槛或需要确认的操作时，会暂停并保留任务进度。

## 安装

1. 从 GitHub 下载 `browser-agent-dom-1.0.zip` 并解压；解压后的目录根部直接包含 `manifest.json`。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择刚解压出的、根目录直接包含 `manifest.json` 的文件夹。
5. 固定 Browser Agent 扩展图标，打开侧边栏并按页面提示配置模型提供商。

扩展包不包含模型 API 密钥或本机评测配置。请在扩展自身的配置界面输入你自己的提供商信息；不要把密钥提交到代码仓库、问题报告或截图中。

## 使用

打开要操作的网站，在侧边栏输入清晰的目标和约束。智能体会读取当前页面并显示任务步骤与进度；页面变化后会重新观察并核验。若站点要求登录、任务缺少必要信息，或操作会产生外部影响，智能体会暂停等待用户处理或确认。

## 权限

扩展使用侧边栏、存储、当前标签页访问、脚本注入、调试器、剪贴板写入和标签页分组权限。它需要访问 HTTP/HTTPS 页面，才能读取并操作用户指定的网站。受浏览器保护的页面、扩展商店页面和受组织策略限制的页面可能无法操作。
