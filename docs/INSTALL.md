# 安装与首次配置

## 从压缩包安装

1. 下载 `browser-agent-dom-1.0.zip`，解压到一个固定位置。
2. 打开 Chrome 的 `chrome://extensions`。
3. 打开页面右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择刚解压出的文件夹；压缩包内的 `manifest.json` 位于该文件夹根目录。
6. 固定扩展图标，并打开 Browser Agent 侧边栏。

更新时先在扩展管理页移除旧包，再从新的解压目录加载扩展。不要删除仍在使用的本地浏览器配置数据，除非你确定需要重置。

## 配置模型

在扩展设置中选择兼容协议，填写提供商 Base URL、模型 ID 和 API 密钥，并使用设置页的连接测试。请只在扩展配置界面输入密钥；GitHub 提交包不应包含本机密钥文件、截图或测试日志。

## 开始任务

切换到目标网页，在侧边栏输入希望完成的目标、顺序和限制。例如：“在帮助中心找到退款时限并总结来源，不要提交退款申请。”执行期间可在侧边栏查看当前步骤。需要登录、关键资料缺失或需要确认高影响操作时，按提示处理后继续。
